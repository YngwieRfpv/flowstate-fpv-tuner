Dieser Ordner ist der feste Platz für den Guide. Die Einzeldatei liegt bereits im Drive-Ordner FPVGuide/Tuner/GitHub Versionen/FPV_Guide_GitHub_Beta_v1.0.1-beta.1 und muss nur noch hierher kopiert werden.

Einspielen — automatisch

$ ./scripts/install-versions.sh \
    --guide ~/Downloads/FPV_Guide_GitHub_Beta_index.html

Einspielen — manuell auf GitHub

# Repository → guide/ → Add file → Upload files
# Datei in index.html umbenennen, committen, pushen

Wichtig für diese Datei

Der Guide ist bewusst eine einzelne, etwa 7 MB große HTML-Datei. Nicht auf ein CDN, Remote-Skripte oder eine Build-Pipeline umstellen, ohne die Offline-Nutzbarkeit ausdrücklich neu zu testen. Sbang-Inhalt, -Ablauf und -Implementierung bleiben unverändert.

$ node scripts/validate.mjs
